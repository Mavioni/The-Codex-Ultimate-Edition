
# Codex of Becoming v1.0

This is the complete deployment-ready package for the Codex of Becoming portal.

## Contents
- `manifesto/`: Landing page with 3D multiversal icosahedron
- `oracle/`: Interactive oracle interface with glyph selector and journaling
- `engine/`: Ritual engine configuration JSONs
- `assets/qr/`: QR portal access
- `assets/scrolls/`: Invocation scrolls and animations
- `rituals/`: Daily ritual guidance and templates

## Deployment
- Upload to GitHub and connect to Netlify
- Publish directory: `.`
- Homepage: `/manifesto/`

## Project Philosophy
The Codex is a sacred interface—built not just for interactivity, but awakening.
